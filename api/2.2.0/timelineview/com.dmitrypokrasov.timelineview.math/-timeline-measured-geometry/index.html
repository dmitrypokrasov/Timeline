interface TimelineMeasuredGeometry

Дополнительный протокол измерения; существующие стратегии не обязаны его реализовывать. Вместо автоматического расширения getContentRows стратегия сама размещает измеренные блоки. Между предварительным и измеренным проходами порядок шагов и ширины текста неизменны.
