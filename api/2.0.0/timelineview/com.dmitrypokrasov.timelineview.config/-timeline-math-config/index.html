data class TimelineMathConfig(val startPosition: TimelineMathConfig.StartPosition = StartPosition.CENTER, val steps: List<TimelineStepData> = listOf(), val spacing: TimelineMathConfig.Spacing = Spacing(), val sizes: TimelineMathConfig.Sizes = Sizes(), val progressMode: TimelineMathConfig.ProgressMode = ProgressMode.SEQUENTIAL, val horizontalLayout: TimelineMathConfig.HorizontalLayout = HorizontalLayout.FIT, val minCellWidth: Float = 160.0f, val pixelsPerMillisecond: Double = 0.001)

Positioning and sizing input for a timeline math engine.

This object stores declarative input only. Concrete coordinates and paths are calculated by com.dmitrypokrasov.timelineview.math.TimelineMathEngine implementations.
